# 🌾 Farma Land

A multiplayer farming simulation game currently under development in Roblox Studio.

The project focuses on building scalable multiplayer gameplay with modular server-side architecture, persistent player progression, and realistic farming mechanics.

> 🚧 This project is actively under development.

---

# Overview

Farma Land is a multiplayer farming game where players own land, expand their farms, manage resources, earn money, and gradually automate farming operations.

The long-term goal is to build a simulation that emphasizes progression, player ownership, and server-authoritative multiplayer systems.
